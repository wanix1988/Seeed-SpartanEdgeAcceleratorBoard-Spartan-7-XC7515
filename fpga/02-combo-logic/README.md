# E02 组合逻辑设计

对应手册：**`docs/manuals/SEA-Dev-Manual-Experiment.pdf`** 第 29 页起（Experiment 2）。

## 目的（摘自手册）

1. Learn the basic grammar of verilog. 2. Master the programming design method of combinatorial logic (such as 4-2 encoder, 2-4 decoder). 3. Consolidate the foundation of Verilog programming design under the Vivado environment.

## 内容

1. Achieve the combinational logic: encoder/decoder (4-2 encoder, 2-4 decoder). 2. Complete timing waveform simulation. 3. Bind pins to I/O and LED for download verification. 2.3
